# 认知结构层审计

本文件用于小说改稿与后置审计。它处理的不是某个词像不像模型，而是叙事单元是否长期以同一种方式闭合。不得把本文件的词表、代理条件或机械命中交给外部正文模型；生成侧只使用 `external-model-card.md` 的正向原则。

## 先冻结边界

开始前固定事件、选择、因果、场景顺序、人物知识、第一人称可见范围、科研语义、证据强度、时间、地点、物品、关系阶段和章末接口。结构层调整若改变其中任一项，撤销对应改动并返回专业审查。

认识论限制语、完整验证过程、精确对白和动作标点都不是天然错误。问题只在它们成簇、周期化，并持续替代情节、关系和生活本身。

## 标出认知呈现档位

逐场找出叙述者的判断段，标记为下列一种：

- `FULL`：观察、枚举解释、排除越界、给出最低结论全部落纸。只留给真正改变风险、关系、资源或行动的节点。
- `COMPRESSED`：只写会改变当前行动的结论，再留一个人物化痕迹。读者已经认识人物时，不重复完整过程。
- `DEFERRED`：当场只记观察或疑问，推理在后文的笔记、独处或后续证据中发生。
- `INTERRUPTED`：思路被现实任务、他人插话、疲惫或时间压力打断，暂不闭合。
- `BEHAVIORAL`：不写内部步骤，只写验证、追问、留记号、收回材料或决定不说等行为，让读者反推谨慎。

同一章可有一到数处 `FULL`，但不得用固定配额裁决。判断标准是该过程是否改变人物接下来的选择。多余的 `FULL` 优先改为 `BEHAVIORAL` 或 `COMPRESSED`；确有后续功能时可改为 `DEFERRED`。这些只作为 `BOUNDED_REPHRASE` 的子类型，不新增项目顶层处置枚举。

谨慎的人不会在所有领域、所有关系和所有疲劳状态下同样谨慎。熟悉的低风险问题可以直接判断；高风险暴露才值得完整校验。允许人物出现不触及事实底线的小误判，并由后续行动或证据纠正，但不得为了自然度强造错误。

## 检查认识论限制语簇

圈出“我不知道、判断不了、只能说明、证明不了、不等于、不声称、无法推出”等限制语，逐处判断：

1. 删除后是否会把可能写成事实、相关写成因果或局部写成整体。会则 `KEEP`。
2. 是否连续几句都在重复同一证据边界。是则合并为一次最准确的限制，或让人物以收手、暂缓、再查证等行为体现。
3. 是否只是在向读者重复人物已经用行动执行过的谨慎。是则 `DELETE_TAIL` 或 `BOUNDED_REPHRASE/BEHAVIORAL`。
4. 是否为科研定义、方法、证据等级或安全信息所必需。是则准确性优先，不为自然度降频。

目标是降簇和内化，不是清除限制语。任何造成过度断言的修改必须撤销。

## 拆开单元测试式对白

为每句专业对白同时写两个旁注：它传递什么信息；它在完成什么社交动作。社交动作可以是试探、遮掩、控制暴露、保住面子、拖延、结束话题、确认边界或争取时间。

若对话长期呈现“提出一个歧义—完整关闭—提出下一个歧义”，按顺序检查：

- 能否把两个相关问题合并回答，或先答人物更在意的那一个。
- 非关键歧义能否搁置、晚些回收，或永不显式回收。
- 人物能否准确地说“不确定，我得再查”，而不是当场补齐全部方法学。
- 听者能否先按自己的目标追问、误解半步或转移话题，再由后文证据纠正。
- 环境任务、第三人和时间压力是否会自然打断本轮。
- 不完整回应是否恰好体现人物控制暴露范围，而非作者遗漏。

关键术语、数据、证据等级和必要定义仍须准确。准则是：准确不等于当场完整；闭环可以下降，错误率不能上升。

## 解除动作与论证的一一配对

把动作分为四类：

- `PHYSICAL`：冷、饿、疲惫、光线、座椅、赶时间等身体与环境维持。
- `RELATIONAL`：递物、让路、站位、保持距离、触碰与撤回等关系动作。
- `LIFE_TEXTURE`：同学整理东西、闲聊、出错、无即时主情节功能的校园生活。
- `ARGUMENT_CUE`：专门为某个结论配的抬眼、停手、敲桌、转身或物件特写。

发现多个论证转折都紧跟 `ARGUMENT_CUE` 时，不要一律删动作：

- 让部分论证节点不配动作，直接由对白或思绪承担。
- 将部分动作移回它自己的身体、关系或生活功能。
- 允许日常动作打断思考，而不是给思考伴奏。
- 保留已经构成人物边界、空间连续性或校园生活的动作。

动作总量不是目标，功能分布才是。不得为了“去配对”破坏站位、持有关系或第一人称所见。

## 识别换皮的功能微循环

不要只找重复词。把相邻叙事回合各写成一个功能序列，例如：

`现场重置 → 再次尝试或说明 → 重新核验不确定性 → 局部收束`

若三个以上回合虽然换了物件、动作、背景声音或说话人，却仍完整重复同一序列，登记`FUNCTIONAL_MICRO_LOOP`。逐回合检查它是否至少改变一项：人物下一步行动、风险、关系、知识、资源或不可逆后效。没有改变者优先压缩为一次；有改变者保留差异，不得为消除形状抹平递进。

常见表现包括：

- 每次失败后都重新摆放物件、重试、列竞争解释并再次得出“不确定”；
- 教师、同伴和叙述者轮流把同一标准重新说清；
- 每次段落换挡都先让环境安静或嘈杂、再收拾物件、再恢复思考；
- 同一生活物件反复作为开始、停顿、解释和收尾标点，却没有新的身体或关系后效。

`FUNCTIONAL_MICRO_LOOP`是人工审计标签，不证明作者身份，也不自动授权删除。先列必须保留的不同功能，再处理相同功能。

## 松开章末过度闭合

先写一张章末接口清单，只列必须传给下一章的事实、选择、关系变化和悬念。再检查结尾是否同时完成：意象回收、主题陈述、证据总结、关系定调、悬念抛出。

如果后三段把多项功能同时做满，优先只保留最必要的一到两项。该数字是编辑提醒，不是句数配额。可以：

- 让悬念停在尚未回答的问题或人物下一步意图上。
- 删除已经由动作成立的主题解释。
- 把一个意象留给后章，不在本章回收。
- 让最后一拍落在声音、温度、普通对话或未完成动作上。

章末接口内的信息不得删除。松开闭合不是故意写散，而是不替读者把所有意义同时结算。

## 处置与记录

继续使用项目固定动作：

- `KEEP`：命中形状，但属于必要科研限定、人物核心高光、关系动作或有效节奏。
- `DELETE_TAIL`：删除动作、对白或段落已经表达过的解释尾巴。
- `BOUNDED_REPHRASE`：只改表达；可附子类型 `COGNITIVE_COMPRESSION / DEFERRED_DISCLOSURE / INTERRUPTION / BEHAVIORALIZATION / DIALOGUE_DEUNITTEST / ACTION_DESYNC / ENDING_UNPOLISH`。
- `REVIEW_FLAG`：机械代理或人工无法安全裁决，保留原文交冷读或专业复查。

每项改动记录原位置、结构问题、处置动作、冻结边界核对和是否影响章末接口。不得按命中数给正文打总分，也不得声称已通过任何外部检测器。

## 冷读问题

- 本章哪里值得让读者完整看到人物的推理，哪里只需看到他做了什么。
- 专业对白是否既准确，又仍由关系、疲惫、面子和时间压力推动。
- 是否每当叙述下结论，人物的手、眼睛和身体就准时配合。
- 删掉最后一句或最后一层解释后，悬念和人物选择是否仍然成立。
- 哪些看似“不够完整”的地方，实际给后文和读者留下了参与空间。
