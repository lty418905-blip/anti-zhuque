# 非虚构文本审计

## 事实和来源优先

- 不为自然度删掉必要限定、来源、数字、方法、风险或适用范围。
- 不伪造个人经历、采访、案例、引语、统计和阅读过程。
- 材料不足时追问、研究、显式保留未知或缩短文章。
- 观点与事实分层，推断说明依据，争议问题说明不确定性。

## 避免模型化论证轨迹

常见深层形状包括：每节先下定义，再列三点，再加反方，再平衡总结；每段都以“问题、解释、结论”闭合；连续使用“需要指出、值得注意、这意味着”等元话语。

修订时：

- 让材料、案例、问题或实际决策承担结构，不靠连接词播报结构。
- 相关限定集中写一次，不在每段重新免责。
- 反方只在真实影响结论时展开，不机械制造正反平衡。
- 同类小点可以合并，不强求三项或五项。
- 结论给出读者下一步、适用边界或仍未知之处，不复述全文目录。

若同一论证程序、免责方式、案例功能或段尾总结跨多个章节反复出现，按`DISTRIBUTED_VOICE`处理。不要删一个连接词或末句后宣称全文已经改善；应由作者级重写重新安排材料进入顺序、证据权重和说话位置，同时冻结事实、来源、立场与必要结论。

## 保留作者位置

- 明确作者凭什么判断：亲历、资料、专业经验、计算或推断。
- 个人口吻来自真实偏好、选择标准和材料接触，不来自伪造口语错误。
- 专业内容可以清楚、严谨、结构化。目标是消除重复功能，不是把正确说明写散。

## 教程与科普

- 步骤顺序、安全警告、前置条件和失败处理必须完整。
- 可以删掉每一步后的道理复述，但不能删掉执行所需信息。
- 示例应覆盖真实难点，不为展示丰富而堆砌同构例子。
- 技术术语不要随机换同义词；稳定命名比表面词汇多样更重要。

检测报告必须在盲态全文冷读之后使用。分段定位只作用于对应文字区间；单次分数不能独立触发删句，也不能替代事实核验和读者任务。
