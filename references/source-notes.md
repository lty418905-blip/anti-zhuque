# 来源说明与能力边界

本 Skill 参考了以下公开材料的方法类别：

- `human-writing` Skill 的材料、说话位置、人物行动、反模型套话和冷读流程。
- 用户提供的朱雀检测六维概述：困惑度、爆发性、语义连贯性／语义指纹、词汇分布、句法规律和多模型融合。
- `https://github.com/qoqu/anti-zhuque` 的公开 README、`main.py`、`analyzer.py` 与小说 Prompt。

对该仓库的核对结果：

- 它是纯本地启发式文本分析器，不是真实朱雀模型实现。
- 源码使用固定词表、正则、句长统计、句首／句型重复和段间统计。
- 它没有计算真实语言模型困惑度，也没有接入朱雀的多模型特征库。
- 小说 Prompt 中的固定句长差、段长和感官配额不适合作为文学硬规则。
- 仓库根目录未发现可确认的许可证文件，因此本 Skill 不复制其代码、完整词表、阈值或 Prompt 文本，只独立实现通用、可解释的形状提醒。

本 Skill 不能保证绕过任何检测器。检测器版本、训练数据和阈值可能变化，且会误报人类文本。输出必须表述为“自然度审计”或“代理提醒”，不能表述为真实朱雀结论。

`human-writing` 以 MIT License 发布。本包保留 `LICENSE-human-writing`，并完整整合其核心说明、五份文体／改稿参考和检查脚本。`qoqu/anti-zhuque` 未发现可确认许可证，因此只参考方法类别，没有复制其代码、阈值、完整词表或 Prompt。
