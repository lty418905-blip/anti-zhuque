# 场景级认知与闭合审计

本文件补足词句、句长和局部模板检查看不见的场景级规律。它只生成可定位的编辑提醒，不推断作者身份，不模拟任何真实检测器，也不输出总分。

## 先做场景三栏冻结

逐场记录：

1. `EVENT_LOCK`：本场必须发生且不得被自然度修改改变的事件、选择、因果和接口。
2. `COGNITIVE_CEILING`：各人物在本场最多能理解、确认和说清到什么程度。
3. `UNRESOLVED_RESIDUE`：本场允许留下的未答问题、误读、延迟回应或未兑现注意。残留不是机械悬念，不要求人物意识到自己漏了什么。

关系场景再写双方各自的即时议程。双方可以完成关键交接，却不必对关系性质形成同步判断。

冻结后先做一次不知道检测分数和高风险段位置的完整冷读，并写出`PRIMARY_FINDING_ID / PRIMARY_MECHANISM / FINDING_SCOPE / VOICE_PROTECTION`。主病灶没有确定前，不开始逐句删改。

## 八项场景级审计

### 1. 认知流程周期化

标出连续段落中的感知、推断、验证、定性。若多个段落反复走完相同流程，问它们是否都改变后续行动、关系、资源或风险。只让关键节点完整展开；其余可压缩、延迟、中断、跳过或在错误前提下暂时失效。

### 2. 动作后即时解释

检查动作后两句内是否总有唯一意义说明。删掉解释仍不影响因果和人物知识时，用`DELETE_EXPLANATION_TAIL`。含义必要但不必当场出现时，用`DELAY_OR_DISTRIBUTE_MEANING`。第一人称对自己动作的偶发自我拆台可保留；替他人动作关闭全部解释空间要更谨慎。

### 3. 连续否定与排除

“没有……也没有……”“不是……而是……”和认识论限制语只有在人物确有排查动机、科研定义或安全边界时才成簇成立。判断重点是动机与语义空间，不是计数。删改不得把可能写成事实或把相关写成因果。

### 4. 对话单元测试化

检查对话是否长期为“问一个歧义—完整回答—关闭—下一问”，以及交谈时周围世界是否停转。关键事实可以准确传递，但允许人物按自己的议程偏答半步、搁置次要问题、听岔、改口、沉默或稍后回应。

### 5. 物件多功能过载

列出同一物件在单场内承担的主要功能：证据、边界、关系信号、主题意象、章末接口等。多功能物件不是错误；若多层意义在同一场同时被解释到位，保留事件必需功能，把其余意义推迟到后文或交给既有其他元素，不为分流发明新物件。

### 6. 段尾、场尾与章尾过闭合

连续检查段尾是否都在定性、总结或点题，场尾是否把所有问题清零，章尾是否同时回收意象、主题、证据、关系和悬念。保住固定出口，只删除已经由动作成立的说明。普通动作、声音或未完成事项可以收尾，但不得机械制造钩子。

### 7. 生活事件后效

生活动作可分别改变注意力、节奏、选择，或明确只承担纯质感。获批事件按其后效窗口影响后续动作；纯质感合法，但不能让全章生活细节都与后文无关。若必须新增事件才能证明细节“有用”，停止本地清洗。

### 8. 同章内部对照

若有可靠的分段反馈，只比较同章高低风险段在上述七项上的差异。新假说至少找另一章反例后再进入规则。不得把长度、某个词或某类场景直接当作通用判据。

检测报告必须在独立冷读之后使用，并按`detector-evidence-and-reverse-effect.md`核验输入可比性。单次报告只提供外部定位提醒；报告分段改变、字符合计不一致或输入格式未锁定时，不得从分数变化推导删句因果。

### 9. 同功能微循环

给每个相邻叙事回合写一行功能，不写原句摘要。若不同表面材料都在重复“重开场—尝试／说明—核验—收束”，检查每一轮是否改变行动、风险、关系、知识、资源或后效。只换动作、物件或说话人而功能不变时，标记`FUNCTIONAL_MICRO_LOOP`；不能因为没有重复词就放过。

先写`FUNCTION_SURVIVOR_LIST`，列出必须保留的递进拍点。压缩只能合并同功能回合，不得删除真正改变后续的失败、误读、证据边界、关系动作或生活余波。

### 10. 装配接缝、引文来源与复写

融合稿或分段装配稿先检查相邻段落是否共享连续八个以上可见文字、正文中部是否出现异常多重空白、以及“回到／又读／重新看”后引出的文字是否真的在上文页面、对白或材料中建立。机械代理只能标出复写、空槽和未建立引文候选，不能判定缺句或擅自补句。逐字复写优先回查作者轮次与装配证据；引文内容与既有对象不一致时交获授权正文作者，不能由审计任务猜原句。

### 11. 对象层与叙述层分轨

提纲或任务若要求人物分类句子、解释规则或核对证据，相关页面文字和必要规则对白属于对象层。审计对象是叙述如何承载这项活动，不是取消活动本身。开审前可用源路径绑定的行区间豁免清单，逐项声明对象层范围、finding类型和理由；只能抑制完整落在范围内的机械提醒。叙述层的重复证明、动作注释、声线趋同和装配硬伤不因同场存在对象层而自动豁免。

### 12. 背景节拍与声线趋同

连续记录背景事件是否总在人物沉默、等待或论证换挡时准时出现。两次以上对齐只生成审阅候选，人工继续判断背景是否真的影响注意、行动、关系或后续状态。再比较对白与叙述者内心是否反复共享“X是X”“A归A”“一种／另一种”等规则断言和二元权衡签名。共享一句不构成缺陷；跨三处以上且需要共同换声时按`DISTRIBUTED_VOICE / NEXT_AUTHOR_HANDOFF`处理，禁止局部同义替换。

## 清洗决策树

1. 触及事件、因果、科研、知识、关系、时间、视角或章末接口：`REVIEW_FLAG`，本地不动。
2. 删除一处后前后无需连改且必要语义不失，并且“没有检测器时仍会删”、不损害`VOICE_PROTECTION`、直接命中`PRIMARY_FINDING`：`DELETE_EXPLANATION_TAIL`。
3. 功能可移到本章既有位置，且只影响两个明确位置：`DELAY_OR_DISTRIBUTE_MEANING`。
4. 单句或单个短段可以一次改清、不改变事实：`BOUNDED_REPHRASE`。
5. 同一模式跨三处以上、修一处会牵动其余处、需要重排场景或双议程：`NEXT_AUTHOR_HANDOFF`，锁定同声线并停止本轮全部替代性局部清洗。没有实际进入下一作者时保持正文不变，登记`PRIMARY_FINDING_UNRESOLVED`。
6. 属于人物声音、科研排除、正当章尾或其他误报：`KEEP`并登记理由。

用户明确授权一次有界修正时，可用`PATTERN_BOUNDED_REVISION`标记范围，但它不是新的顶层处置动作，也不能把分布式问题改名为局部问题。只有以下条件全部满足才可使用：

1. 同一功能模式的全部实例已经穷举为有限锚点；
2. 每个锚点都列出`EVENT_LOCK / FUNCTION_SURVIVOR_LIST / VOICE_PROTECTION`；
3. 各处实际动作仍只使用`KEEP / DELETE_EXPLANATION_TAIL / DELAY_OR_DISTRIBUTE_MEANING / BOUNDED_REPHRASE`；
4. 区外正文可以机械锁定，改动不要求重排场景、改变双议程或新增事实；
5. 一次通读和一次接缝复核即可闭合；执行时若又发现未列实例，立即停止并恢复`NEXT_AUTHOR_HANDOFF`。

该范围标签适合两个相邻区域呈现同一微循环、且每处都可独立压缩的情况。它不适合跨全章重塑声线、逐个替换检测命中词或把许多零散润色拼成一次“有界”改稿。

所谓有界，是改完这一处即可合上文档。只要修复自然引出“其他地方也应一起改”，就已经是分布式声线问题。

若只处理次要局部问题，版本结论必须是`LOCAL_CHANGE_ONLY`，不得把版本命名为全章自然度改善。科研或世界观PASS不改变这一文学结论。

## 生成端与审计端隔离

正文模型只接收正向约束：注意有偏向，理解有上限，动作可晚些显出意义，双方有不同议程，生活动作会留下后效。不得把检测分数、词表、阈值、命中位置或本文件的逐项审计表塞给正文模型。
