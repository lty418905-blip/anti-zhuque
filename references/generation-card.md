# 正向生成卡

本文件用于第一稿。只给正向写作原则，不给检测词表、统计阈值和风险标签。

复杂任务使用`../assets/structured-single-model-input-v2-split.xml`时，本文件的核心约束已经以NPA-01—NPA-14嵌入模板。不要再把本文件全文复制到同一输入中；模型仍应读取本文件理解原则，但用户输入只保留一份结构化约束，避免同义规则挤占注意力。旧V1模板仍兼容。

## 所有体裁

1. 先确定一个具体说话者、具体读者、写作目的和当下处境。事实不够时追问、研究、缩短或显式保留未知，不用重复解释灌字数。
2. 信息按说话者真正会注意到的顺序出现，不按“定义、三点、总结”的默认模板排序。
3. 几个表达同样准确时，不必总选最完整、最圆滑、最像标准答案的那个。优先选择符合身份、关系、经验和压力的说法。
4. 具体名词、动作、物件、后果和例子优先于抽象评价。例子必须真实、可推导，或在虚构文本中由设定支持。
5. 允许普通句子和普通段落承担连接工作。不是每段都需要金句、升华、悬念或漂亮收尾。
6. 不重复翻译同一个意思。例子、动作或事实已经成立后，不追加一句替读者解释意义。
7. 节奏跟随内容。赶时间、争论、列步骤、回忆和犹豫本来就有不同句长，不按数字配额制造起伏。
8. 精确内容始终选择最准确表达，包括事实、数字、时间、因果、术语、安全信息、引语和证据等级。

## 虚构文本

1. 场景由人物目标、阻力、行动和离场变化托住，不靠心理解释与景物堆积补长度。
2. 对白既传递信息，也完成试探、遮掩、争取、拒绝、保住面子或改变距离等社交动作。
3. 人物可以说半句、改口、误解半步、答自己更在意的问题，或把非关键问题留到后面。
4. 动作服务身体、空间、关系和生活，不为每一个观点安排一个抬眼、停手或敲桌。
5. 谨慎人物只在真正改变风险和行动时展开完整推理，其他时候用追问、核对、留记号、暂缓决定等行为呈现。
6. 严肃感从选择、代价和后果中产生。优美描写留给真正挣得的关系位移、损失或认知裂缝。

## 非虚构文本

1. 开头直接进入问题、材料、矛盾或一个能承担全文的具体例子。
2. 论证可以有结构，但不把每个小节都写成“观点、解释、例子、总结”的同形模块。
3. 必要限定保留一次最准确表达，不连续换说法重复免责。
4. 反方、例外和不确定性只在真实相关时出现，不为显示全面而机械配平。
5. 结尾完成读者需要的动作或判断即可，不复述全文提纲，不宣布文章价值。

写完完整初稿后停止。不要在本阶段打开深层审计文件。
